[SLIDE 2]
Introduction
Background: Bone fracture assessment relies extensively on diagnostic X-ray radiography. Deep learning and CNNs provide automated feature extraction for radiological pattern recognition.
Current Scenario & Challenges: Manual interpretation requires specialized radiologists, is susceptible to fatigue, and subtle/hairline fractures remain difficult to identify during rapid triage.
Application Area: Medical Image Analysis • Computer-Aided Diagnostic Screening • Clinical Decision Support • Healthcare AI.
Why Address This Problem: Need for consistent computer-assisted screening, explainable attention maps for clinical trust, and evaluation of robustness beyond a single dataset/domain.
2
--------------------------------------------------------------------------------

[SLIDE 3]
Problem Identification
Existing Problem: Deep learning fracture classifiers achieve high in-domain accuracy but suffer severe performance degradation and high false-positive rates when tested on external hospital datasets.
Limitations of Current Approaches: Domain shift from differing scanner hardware, intensity distributions, and non-fracture artifacts. Conventional attention mechanisms fail to capture inter-attention divergence.
Who is Affected: Radiology departments with heavy caseloads, emergency diagnostic centers, clinicians needing reliable screening support, and patients awaiting timely treatment.
Core Need: A robust fracture classification system investigating adaptive attention mechanisms (DG-CBAM), explainability, and multi-domain evaluation.
3
--------------------------------------------------------------------------------

[SLIDE 4]
Problem Statement
Problem Statement: "Develop a deep-learning-based system capable of classifying bone X-ray images into fracture and non-fracture categories while improving attention-based feature representation and evaluating robustness across different image domains."
Key Challenges: Detecting subtle fracture lines, suppressing false positives across diverse scanners, and adaptively fusing channel and spatial attention cues.
Expected Improvement: Enhanced feature representation via proposed DG-CBAM, more focused attention maps, and empirical evaluation across internal and external benchmarks.
Project Scope: Binary fracture/non-fracture classification from user-uploaded X-rays, prediction confidence estimation, Grad-CAM explainability, and research decision support (not replacing clinicians).

[SLIDE 6]
Research Gap
1. Existing Research: CNN & DenseNet architectures for medical image feature extraction; standard attention mechanisms (CBAM); explainable AI methods (Grad-CAM) applied to single-source datasets.
2. Remaining Limitations & Gaps: 
   • Cross-Domain Degradation: Models overfit native training scanner distributions and suffer massive false-positive inflation on unseen external clinical datasets.
   • Attention Fusion Rigidity: Conventional CBAM applies channel and spatial attention sequentially without modeling the difference (|Mc - Ms|) between spatial and channel cues.
   • Lack of External Stress Testing: Existing works rarely benchmark models on an independent, zero-leakage external dataset.
3. Our Proposed Approach: Proposed DG-CBAM with learnable parameter γ + controlled ablation studies (Exp A to E) + rigorous zero-leakage external benchmark evaluation on FracAtlas.

[SLIDE 8]
Proposed Solution
Overall Concept: BoneGuard AI — An intelligent deep learning decision-support framework designed for automated fracture classification with adaptive attention refinement and cross-domain awareness.
Key System Components: 1. X-ray Upload & Validation → 2. Intensity Normalization → 3. DenseNet121 Backbone → 4. Proposed DG-CBAM Attention → 5. Binary Classifier Head → 6. Confidence Score → 7. Grad-CAM Visualization → 8. React.js Dashboard.
Research Novelty — Proposed DG-CBAM: Extends conventional CBAM by incorporating a difference-guided attention mechanism:
        M_new = M_s + γ · |M_c − M_s|
Where M_s = spatial attention, M_c = channel attention, and γ = learnable parameter.
Mechanism Rationale: Allows the network to adaptively emphasize complementary differences between channel and spatial attention maps rather than relying on a rigid sequential cascade.

Phase 7: External Benchmark Generalization & Explainability: Evaluate out-of-domain robustness on FracAtlas (N=4,068) and perform Grad-CAM heatmap analysis.

System Architecture / Block Diagram
1. INPUT LAYER: Pre-acquired digital X-ray image uploaded by the clinician via the React.js web interface.
2. PREPROCESSING & VALIDATION: Image validation → Resolution alignment (224x224x3) → Intensity normalization → Channel formatting.
3. DEEP LEARNING CORE (BONEGUARD AI): 
   • DenseNet121 Feature Backbone: 4 Dense Blocks with dense feature reuse and transition layers.
   • Proposed DG-CBAM Modules: Dynamic feature recalibration: M_new = M_s + γ · |M_c − M_s|.
   • Classification Head: Global Average Pooling (GAP) → Fully Connected Layer → Sigmoid Activation.
4. DECISION SUPPORT & EXPLAINABILITY OUTPUT: Binary Classification (Fracture / Non-Fracture) • Prediction Confidence Score (%) • Grad-CAM Visual Heatmap Localization • React.js Clinical Decision Support Dashboard.

[SLIDE 15]
Novelty / Innovation
1. Proposed Difference-Guided CBAM (DG-CBAM): 
   • Conventional Attention: Applies channel (Mc) and spatial (Ms) attention sequentially without inter-attention divergence modeling.
   • Proposed Formulation: M_new = M_s + γ · |M_c − M_s|, adaptively emphasizing complementary attention differences.
   • Learnable Parameter γ: Dynamically optimized via backpropagation (converged to mean γ ≈ 0.1038 across dense stages).
2. False-Positive Reduction on External Data: Achieved 447 FP reduction (1,862 vs 2,309 in original DG-CBAM and 2,646 in CBAM) while maintaining high sensitivity (75.32% recall).
3. Multi-Domain Validation & Explainability: Rigorous zero-leakage cross-domain testing on 4,068 external images + Grad-CAM decision support.
