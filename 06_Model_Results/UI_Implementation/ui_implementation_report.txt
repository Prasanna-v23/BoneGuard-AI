2. MODEL & CHECKPOINT SPECIFICATIONS
--------------------------------------------------------------------------------
Model Architecture:
  - Backbone: DenseNet-121 (Dense Feature Reuse across 4 DenseBlocks)
  - Attention Module: Proposed Difference-Guided CBAM (DG-CBAM)
    Formulation: M_new = M_s + γ · |M_c - M_s|
    Inserted at output of each DenseBlock (stages 1, 2, 3, 4)
  - Classification Head: AdaptiveAvgPool2d(1) -> Flatten -> Linear(1024, 2)
  - Total Parameters: 7,259,406 (All trainable)

Selected Deployment Checkpoint:
  - Checkpoint Path: 06_Model_Results/DGCBAM_DomainRobustness/Exp_E_ClassWeight/best_model.pth
  - Checkpoint Size: 28.28 MB
  - Configuration: Exp-E (Unweighted CrossEntropyLoss [1.0, 1.0])
  - Reason for Selection: Best verified balance of in-domain classification
    (99.64% test accuracy, 100% precision) and domain robustness (reduced 447
    false positive alarms on external FracAtlas benchmark).
  - Learned Mean Gamma (γ): 0.1038
    Stage 1: 0.1015
    Stage 2: 0.0981
    Stage 3: 0.1024
    Stage 4: 0.1134

4. GRAD-CAM EXPLAINABILITY IMPLEMENTATION
--------------------------------------------------------------------------------
  - Target Layer: model.features.norm5 (1024 channels output before pooling)
  - Target Class: Class 0 (FRACTURE) for backpropagation score gradient
  - Forward/Backward Hooks: Captures activations and gradients with retain_graph=False
  - Processing:
      1. Global average pooling of gradients: weights = mean(grad, dim=(2,3))
      2. Weighted activation sum: cam = relu(sum(weights * activations))
      3. Normalization to [0.0, 1.0] range
      4. Cubic interpolation resize to 224 x 224
      5. OpenCV COLORMAP_JET application
      6. Alpha blending with input radiograph (alpha = 0.45)
      7. Base64 PNG encoding for zero-disk-write frontend transfer
  - UI Views: Overlay, Heatmap, Original Radiograph, Side-by-Side Comparison
